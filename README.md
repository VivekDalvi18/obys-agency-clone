# Obys Agency Clone

A frontend recreation of the **Obys Agency** website built to practice modern web design, animations, smooth scrolling, and interactive user interfaces.

## 🚀 Live Demo

[View Live Demo](https://vivekdalvi18.github.io/obys-agency-clone/)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GSAP
* Locomotive Scroll

## ✨ Features

* Responsive website layout
* Smooth scrolling
* GSAP-based animations
* Interactive UI elements
* Custom typography and styling
* Page transitions and visual effects
* Modern agency-style design

## 🎯 Purpose

This project was created as a frontend development practice project to improve my understanding of:

* Advanced CSS layouts
* JavaScript DOM manipulation
* GSAP animations
* Smooth scrolling
* Responsive web design
* Creating interactive and visually engaging websites

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/obys-agency-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use **VS Code Live Server** to run the project locally.
